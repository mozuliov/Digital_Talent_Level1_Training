## **Option 1 — Install from Microsoft Store (Easiest & Auto‑Updates)**

**Recommended for all beginners.**

1. Open the **Microsoft Store** on your computer    
2. Search for **“Power BI Desktop”**    
3. Click **Install**    
4. Wait for installation to complete    
5. Launch **Power BI Desktop** from the Start Menu    

**Benefits:**

- Auto‑updates    
- No admin rights needed on most devices    
- Fastest installation path    

## **Option 2 — Install from Microsoft Download Center (Manual Installer)**

Use this if the Microsoft Store is blocked.

1. Go to: [https://aka.ms/pbidesktop](https://aka.ms/pbidesktop)    
2. Scroll down and click **Download**    
3. Choose the installer that matches your system:    
    - `PBIDesktopSetup.exe` (most common)        
4. Run the installer    
5. Follow the on‑screen steps    
6. Launch **Power BI Desktop**    

## 🧪 After Installation — Quick Verification

Ask students to confirm:

- Power BI Desktop opens successfully    
- They see the **Home** ribbon    
- They can click **Get Data → Excel**    
- They can load a sample file    

This ensures everything is working before class.
