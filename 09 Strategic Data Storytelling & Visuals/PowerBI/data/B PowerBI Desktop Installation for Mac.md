>Microsoft does **not** provide a Mac version of Power BI Desktop. Mac users must choose one of the following workarounds.

## ✅ **Option 1 — Use Power BI Desktop via Windows in Parallels (Recommended)**

Best experience for Mac users.

1. Install **Parallels Desktop** (paid or student license)    
2. Install **Windows 11** inside Parallels    
3. Inside Windows, install **Power BI Desktop** using the Windows instructions above    

**Pros:**

- Full Power BI Desktop experience    
- Smooth performance on M1/M2/M3 Macs    

**Cons:**

- Requires Parallels + Windows license (students often get discounts)    

## ✅ **Option 2 — Use Windows via Boot Camp (Intel Macs only)**

Not available on M1/M2/M3 Macs.

1. Open **Boot Camp Assistant**    
2. Install Windows    
3. Boot into Windows    
4. Install Power BI Desktop normally
